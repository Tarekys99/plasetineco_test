# نظام المصادقة المعياري - بيتزا السلام

## نظرة عامة
تم تقسيم نظام المصادقة إلى ملفات منفصلة لسهولة الصيانة والتطوير.

## الملفات والوظائف

### 1. `auth-core.js` - الوظائف الأساسية
- **الغرض**: الوظائف الأساسية للمصادقة والـ API
- **الوظائف**:
  - `apiCall()` - استدعاء APIs
  - `getCurrentUser()` - الحصول على المستخدم الحالي
  - `getUserID()` - الحصول على معرف المستخدم
  - `isLoggedIn()` - فحص حالة تسجيل الدخول
  - `logout()` - تسجيل الخروج

### 2. `auth-forms.js` - نماذج التسجيل والدخول
- **الغرض**: التعامل مع نماذج تسجيل الدخول والتسجيل
- **الوظائف**:
  - `toggleForms()` - التبديل بين النماذج
  - `handleSignup()` - معالجة تسجيل حساب جديد
  - `handleLogin()` - معالجة تسجيل الدخول
  - إعداد مستمعي الأحداث للنماذج

### 3. `account-page.js` - صفحة الحساب
- **الغرض**: عرض وإدارة صفحة حساب المستخدم
- **الوظائف**:
  - `showAccountPage()` - عرض صفحة الحساب
  - `confirmLogout()` - تأكيد تسجيل الخروج
  - عرض معلومات المستخدم والأزرار

### 4. `user-orders.js` - الطلبات السابقة
- **الغرض**: تحميل وعرض طلبات المستخدم السابقة
- **الوظائف**:
  - `loadUserOrders()` - تحميل آخر 3 طلبات
  - ترجمة حالات الطلبات للعربية
  - تنسيق التواريخ والأسعار

### 5. `icon-fix.js` - إصلاح الأيقونات
- **الغرض**: ضمان عمل أيقونات شريط التنقل بشكل صحيح (مبسط بعد إصلاح CSS)
- **الوظائف**:
  - `ensureIconFontsLoaded()` - تحديث بسيط للأيقونات
  - CSS لأنيميشن التحميل
- **ملاحظة**: تم تبسيط هذا الملف بعد إضافة ملفات CSS المفقودة إلى login.html

## إصلاح مشكلة الأيقونات
**المشكلة**: كانت الأيقونات لا تظهر في صفحة الحساب
**السبب**: ملفات CSS المفقودة في login.html:
- `css/icomoon.css` - الملف الأساسي للأيقونات
- `css/flaticon.css` - أيقونات إضافية  
- `css/ionicons.min.css` - أيقونات أخرى
- ملفات CSS أخرى مطلوبة

**الحل**: إضافة جميع ملفات CSS المطلوبة إلى login.html لتطابق index.html و menu.html

## ترتيب التحميل المطلوب
```html
<script src="js/auth-core.js"></script>        <!-- الأساسيات أولاً -->
<script src="js/icon-fix.js"></script>         <!-- إصلاح الأيقونات -->
<script src="js/user-orders.js"></script>      <!-- الطلبات -->
<script src="js/account-page.js"></script>     <!-- صفحة الحساب -->
<script src="js/auth-forms.js"></script>       <!-- النماذج أخيراً -->
```

## APIs المستخدمة
- `POST /users/register` - تسجيل حساب جديد
- `POST /users/login` - تسجيل الدخول
- `GET /orders/user_orders/{user_id}` - طلبات المستخدم

## التخزين المحلي
- `currentUser` - بيانات المستخدم الحالي
  ```json
  {
    "userID": "uuid",
    "firstName": "string",
    "lastName": "string", 
    "phone": "string",
    "email": "string"
  }
  ```

## حالات الطلبات
- `pending` → "في الانتظار" (أصفر)
- `preparing` → "قيد التحضير" (أزرق)
- `ready` → "جاهز" (أخضر)
- `delivered` → "تم التوصيل" (أخضر)
- `cancelled` → "ملغي" (أحمر)

## الصيانة
- كل ملف مستقل ويمكن تطويره منفصلاً
- الوظائف متاحة عالمياً عبر `window`
- تسجيل واضح في وحدة التحكم لكل ملف
- معالجة أخطاء شاملة في كل وظيفة
